# 14 — Stage-aware solve watchdog

**What to build:** The detached watchdog becomes a full-solve monitor: every tick it reports where the sim actually is — initial meshing, adaptive meshing, frequency sweep, finalizing, or done — and it detects completion *normal or otherwise*. Stage detection uses two independent observables: the solve profile's stage ledger (stage names with per-stage elapsed/memory; the terminal status line), and stage-family artifact growth (initial-mesh files → adaptive-pass artifacts → per-frequency sweep entries). Terminal states, each evidenced in the progress file: complete (profile status "Normal Completion" + settle), stalled (no growth in the current stage past its window — catches stuck-at-mesh with its stage in evidence), aborted (in-flight semaphores gone + no completion + solver process dead — catches engine death / memory exhaustion). Any non-Normal profile status is appended verbatim so one read of the progress file distinguishes done from plateau. The sweep-count guess parameter is removed entirely — completion never depends on a count prediction. The watchdog stays filesystem-and-process only: no pyAEDT import, no attach, no LLM babysitting.

**Blocked by:** None — can start immediately.
