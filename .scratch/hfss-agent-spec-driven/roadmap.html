Spec-Driven HFSS Agent

The tool's containment machinery is sound. What it contains is the problem: the agent's primary output is free-form Python. Replace that artifact with a validated design spec and a hand-written compiler, and robustness and token efficiency stop being a trade — they become the same fix.

01Two live bugs first

Found during the review, with reproduction on this box. Both defeat safety machinery the last phase was built to add, and both passed a 72-test green suite.

The safety layer is currently decorative

P0 · 01

Banking never fires. confirm_solve's regex omits the escaped quotes AEDT actually writes, so terminal_status() returns None on 9 of 9 real profiles. Every solved workspace scores proceed, teardown runs close_projects=True, and the results-purge incident ticket 13 exists to prevent is still fully live.

P0 · 02

The watchdog is blind to stage. Family regexes are applied only to filenames, but .imesh, .cmesh and _ADP* are directories — so mesh=(0,0) adp=(0,0) on every real tree. Since the profile is written only at the end of a solve, artifact growth is the sole live signal, and stage detection stays dark until the sweep starts.

CLASS · 03

Fixtures concealed both. Real artifact names written as files where AEDT writes directories; a profile fixture with unescaped quotes. Ticket 14's comments record the escaping correctly — ticket 13 landed minutes later without it. The knowledge had nowhere to live but one comment thread.

02The one change

Every expensive mechanism in the current design exists to contain generated code. Change the artifact and the mechanisms stop being necessary rather than getting cheaper.

Three model seams, not a conversation: clarify, diagnose-on-failure, narrate-QA. Everything between design.yaml and the desktop is tested code. Schema and reference errors cost zero AEDT time; the compiler is idempotent by construction, so ADR 0008 stops depending on the model remembering it per script.

04What survives, what goes

This is a change of artifact, not a rewrite of doctrine. The perf refactor's instincts were right; they were applied one layer too high.

✓Kept unchanged

Sound, and in some cases ahead of the published state of the art.

  • Phase sessions and the State ledger — ADR 0007. Matches the handoff-validity framing the agentic-EDA survey argues for.
  • The Verification line — the compiler still emits every PASS: line.
  • The visual Review gate — ADR 0003. The pilot proved it catches what nothing else does.
  • The detached watchdog — ADR 0006, once ticket 02 restores its stage vision.
  • Delete-then-create — ADR 0008, promoted from discipline to compiler property.
  • Copy-first Re-entry and the Learning loop — ADRs 0001, 0002.

−Deleted, not optimized

Each exists only to contain free-form generated code.

  • The replay ceremony — 12_verify_sync and the port-pinned second desktop, replaced by a document diff.
  • KB signature discovery — ~20 steps at baseline, now zero because it never happens.
  • Per-run script authoring — ten staged scripts re-derived every run, including fixes the pilot already paid for.
  • Most self-correction loops — schema and reference errors are caught before AEDT launches.
  • Log flooding — ~35 process launches dumping pyAEDT INFO into context.

05Risks, honestly

Where this plan could be wrong, and what would show it.

The schema is too narrow
A spec constrains what the tool can express, and Foam-Agent hit exactly this — native meshing was insufficient for novel geometries, forcing an external escape hatch. Mitigation: the raw-pyAEDT path stays supported and flagged, and escape-hatch rate is a tracked metric. If it fires often, the schema is wrong — that's a signal, not a failure. Budget for getting it wrong twice.
Phase 2 is a real rewrite
It is the largest single investment here. That is why ticket 06 runs first: if a capable main-loop model alone recovers most of the gap, the bet shrinks to tickets 09, 13 and 15 — and those are worth doing regardless.
Chat is a weak interface for parametric design
Clarification and QA narrative are excellent model work. Geometry dimensions are not — they want a spec file. The pilot's fatal domain error is exactly the class that a document plus a numeric check catches in seconds.
The value story today
Being straight about it: the tool has produced solved antennas, but so far at a cost above doing it by hand. What it is genuinely accumulating is repeatability and provenance. Whether it becomes useful depends on bending the per-run cost curve, which is what this plan is for.
