# Playbook grows only through approved amendments

The agent's EM-design technique store (the Playbook) is appended to only through the Learning loop's explicit ceremony: fix the current design now, then propose a playbook amendment, and append only after the user approves. Anything else — silent auto-append on success, unvetted web scavenging — is prohibited. Reason: the playbook is the reproducibility contract; an un-reviewed one-off tweak pushed into it contradicts earlier entries and quietly makes every future run wrong in the same ways.
