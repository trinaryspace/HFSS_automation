# add_hdm_bundle_from_file 

HDMPlotter.add_hdm_bundle_from_file(_filename : [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)")_, _units : [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") = None_) → [None](https://docs.python.org/3.11/library/constants.html#None "\(in Python v3.11\)") 
    
Add hdm bundle from file. 

Parameters: 
     

**filename**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Full path to hdm file. 

**units**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)"), `optional` 
    
Units of the hdm file. The default is `None`. If `None`, the units will be set to the units of the first CAD model added.
Examples

```
>>> from ansys.aedt.core.visualization.advanced.hdm_plot import HDMPlotter
>>> obj = HDMPlotter()
>>> obj.add_hdm_bundle_from_file(filename="example.hdm")

```
