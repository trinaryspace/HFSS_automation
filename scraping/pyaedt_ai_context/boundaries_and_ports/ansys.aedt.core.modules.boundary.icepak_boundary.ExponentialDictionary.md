# ExponentialDictionary 

class ansys.aedt.core.modules.boundary.icepak_boundary.ExponentialDictionary(_vertical_offset_ , _coefficient_ , _exponent_coefficient_) 
    
Manages exponential condition assignments, which are children of the `BoundaryDictionary` class. 

This class applies a condition `y` dependent on the time `t`:
    
`y=a+b*exp(c*t)` 

Parameters: 
     

**vertical_offset**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Vertical offset summed to the exponential law, which corresponds to the coefficient `a` in the formula. 

**coefficient**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Coefficient that multiplies the exponential term, which corresponds to the coefficient `b` in the formula. 

**exponent_coefficient**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Coefficient in the exponential term, which corresponds to the coefficient `c` in the formula.
Examples

```

>>> obj = ExponentialDictionary()
