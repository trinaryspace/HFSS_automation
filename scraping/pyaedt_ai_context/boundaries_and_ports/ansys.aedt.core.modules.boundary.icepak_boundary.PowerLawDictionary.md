# PowerLawDictionary 

class ansys.aedt.core.modules.boundary.icepak_boundary.PowerLawDictionary(_intercept_ , _coefficient_ , _scaling_exponent_) 
    
Manages power law condition assignments, which are children of the `BoundaryDictionary` class. 

This class applies a condition `y` dependent on the time `t`:
    
`y=a+b*t^c` 

Parameters: 
     

**intercept**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Value of the assignment condition at the initial time, which corresponds to the coefficient `a` in the formula. 

**coefficient**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Coefficient that multiplies the power term, which corresponds to the coefficient `b` in the formula. 

**scaling_exponent**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Exponent of the power term, which corresponds to the coefficient `c` in the formula.
Examples

```

>>> obj = PowerLawDictionary()
