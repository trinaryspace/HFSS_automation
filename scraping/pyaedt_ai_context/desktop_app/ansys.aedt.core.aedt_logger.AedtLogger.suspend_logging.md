# suspend_logging 

AedtLogger.suspend_logging() 
    
Temporarily disable all logs and restore them afterward.
Examples

```
>>> from ansys.aedt.core import Hfss
>>> hfss = Hfss()
>>> with hfss.logger.suspend_logging():
...     pass  # No logging occurs here

```
