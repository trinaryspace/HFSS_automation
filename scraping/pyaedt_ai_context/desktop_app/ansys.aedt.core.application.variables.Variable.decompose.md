# decompose 

Variable.decompose() → [tuple](https://docs.python.org/3.11/library/stdtypes.html#tuple "\(in Python v3.11\)") 
    
Decompose the evaluated expression into a floating-point number and units. 

Returns: 
     

[`tuple`](https://docs.python.org/3.11/library/stdtypes.html#tuple "\(in Python v3.11\)")
    
The float value of the variable and the units exposed as a string.
Examples

```
>>> from ansys.aedt.core.application.variables import Variable
>>> var = Variable("10mm")
>>> var.decompose()

```
