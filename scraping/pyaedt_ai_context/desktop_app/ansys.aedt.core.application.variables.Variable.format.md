# format 

Variable.format(_fmt : [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)")_) → [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Return the string value using the specified numeric format (‘06.2f’). 

Returns: 
     

[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)")
    
Examples

```
>>> from ansys.aedt.core.application.variables import Variable
>>> var = Variable("10mm")
>>> var.format("06.2f")
