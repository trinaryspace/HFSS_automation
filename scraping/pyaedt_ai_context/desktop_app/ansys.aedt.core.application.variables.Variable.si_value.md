# si_value 

property Variable.si_value: [float](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") 
    
Current value in SI units (float).
This getter keeps the cached SI value in sync with the AEDT backend. It queries the evaluated variable value from AEDT, converts it to SI units using the current unit system and unit string.
Examples

```
>>> from ansys.aedt.core.application.variables import Variable
>>> var = Variable("10mm")
>>> var.si_value

```
