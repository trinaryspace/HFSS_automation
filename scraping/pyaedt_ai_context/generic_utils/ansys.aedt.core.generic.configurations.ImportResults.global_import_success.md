# global_import_success 

property ImportResults.global_import_success: [bool](https://docs.python.org/3.11/library/functions.html#bool "\(in Python v3.11\)") 
    
Returns `True` if all imports are successful. It returns `False` otherwise. 

Returns: 
     

[bool](https://docs.python.org/3.11/library/stdtypes.html#bltin-boolean-values "\(in Python v3.11\)")
    
Examples

```
>>> from ansys.aedt.core import Hfss
>>> hfss = Hfss()
>>> hfss.configurations.import_config(r"C:\Temp\hfss_config.json")
>>> hfss.configurations.results.global_import_success
