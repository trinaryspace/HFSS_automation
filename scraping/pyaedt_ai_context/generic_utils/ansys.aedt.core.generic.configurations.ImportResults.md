# ImportResults 

class ansys.aedt.core.generic.configurations.ImportResults 
    
Contains the results of the import operations.
Each result can be `True` or `False`.
Examples

```
>>> from ansys.aedt.core import Hfss
>>> hfss = Hfss()
>>> hfss.configurations.results
