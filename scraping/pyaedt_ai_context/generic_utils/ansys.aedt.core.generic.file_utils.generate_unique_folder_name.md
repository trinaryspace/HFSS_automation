# generate_unique_folder_name 

ansys.aedt.core.generic.file_utils.generate_unique_folder_name(_root_name : [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") = None_, _folder_name : [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") = None_) → [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Generate a new AEDT folder name given a root name. 

Parameters: 
     

**root_name**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)"), `optional` 
    
Root name for the new folder. The default is `None`. 

**folder_name**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)"), `optional` 
    
Name for the new AEDT folder if one must be created. 

Returns: 
     

[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)")
    
Newly generated name.
Examples

```
>>> from ansys.aedt.core.generic.file_utils import generate_unique_folder_name
>>> generate_unique_folder_name(root_name=r"C:\Projects", folder_name="MyFolder")
