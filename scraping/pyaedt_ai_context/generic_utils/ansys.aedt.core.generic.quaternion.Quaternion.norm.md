# norm 

Quaternion.norm() → [float](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") 
    
Returns the norm of the quaternion.
Examples

```
>>> from ansys.aedt.core.generic.quaternion import Quaternion
>>> Quaternion(1, 2, 3, 4).norm()
5.477225575051661

```
