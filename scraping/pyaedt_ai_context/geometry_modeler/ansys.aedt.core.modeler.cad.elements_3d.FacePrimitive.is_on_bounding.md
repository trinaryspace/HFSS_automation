# is_on_bounding 

FacePrimitive.is_on_bounding(_tolerance : [float](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") = 1e-09_) → [bool](https://docs.python.org/3.11/library/functions.html#bool "\(in Python v3.11\)") 
    
Check if the face is on bounding box or Not. 

Parameters: 
     

**tolerance**[`float`](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)"), `optional` 
    
Tolerance of check between face center and bounding box. 

Returns: 
     

[bool](https://docs.python.org/3.11/library/stdtypes.html#bltin-boolean-values "\(in Python v3.11\)")
    
True if the face is on bounding box. False otherwise.

```
>>> from ansys.aedt.core.modeler.cad.elements_3d import FacePrimitive
