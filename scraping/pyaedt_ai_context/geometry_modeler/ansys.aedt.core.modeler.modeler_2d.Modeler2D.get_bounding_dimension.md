# get_bounding_dimension 

Modeler2D.get_bounding_dimension() → [list](https://docs.python.org/3.11/library/stdtypes.html#list "\(in Python v3.11\)") 
    
Retrieve the x, y and z size of the bounding box for the model.
This method is called without arguments. 

Returns: 
     

[`list`](https://docs.python.org/3.11/library/stdtypes.html#list "\(in Python v3.11\)")
    
List of three float values representing the bounding box dimensions in the form `[dim_x, dim_y, dim_z]`.
References

```
>>> oEditor.GetModelBoundingBox

```

Examples

```
>>> from ansys.aedt.core.modeler.cad.primitives import GeometryModeler
>>> obj = GeometryModeler()
>>> obj.get_bounding_dimension()
