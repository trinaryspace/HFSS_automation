# enable_rigid_flex 

Hfss3dLayout.enable_rigid_flex() → [bool](https://docs.python.org/3.11/library/functions.html#bool "\(in Python v3.11\)") 
    
Turn on or off the rigid flex of a board with bending if available.
This function is the same for both turning on and off rigid flex. 

Returns: 
     

[bool](https://docs.python.org/3.11/library/stdtypes.html#bltin-boolean-values "\(in Python v3.11\)")
    
`True` if rigid flex is turned off, `False`` if rigid flex is turned off. In non-graphical, `True` is always returned due to a bug in the native API.
Examples

```
>>> from ansys.aedt.core import Hfss3dLayout
>>> hfss3d = Hfss3dLayout()
>>> hfss3d.enable_rigid_flex()

```
