# camera_position 

property ModelPlotter.camera_position: [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Get or set the camera position value. This parameter disables the default iso view.
Value for the camera position. The value is for `"xy"`, `"xz"` or `"yz"`. 

Returns: 
     

[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)")
    
Examples

>>> obj.camera_position
