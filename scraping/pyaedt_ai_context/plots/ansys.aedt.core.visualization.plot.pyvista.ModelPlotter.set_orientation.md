# set_orientation 

ModelPlotter.set_orientation(_camera_position : [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") = 'xy'_, _roll_angle : [float](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") = 0_, _azimuth_angle : [float](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") = 45_, _elevation_angle : [float](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") = 20_) → [bool](https://docs.python.org/3.11/library/functions.html#bool "\(in Python v3.11\)")

**camera_position**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)")

**roll_angle**[`int`](https://docs.python.org/3.11/library/functions.html#int "\(in Python v3.11\)"), [`float`](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") 
    
Roll camera angle on the specified the camera_position. 

**azimuth_angle**[`int`](https://docs.python.org/3.11/library/functions.html#int "\(in Python v3.11\)"), [`float`](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") 
    
Azimuth angle of camera on the specified the camera_position. 

**elevation_angle**[`int`](https://docs.python.org/3.11/library/functions.html#int "\(in Python v3.11\)"), [`float`](https://docs.python.org/3.11/library/functions.html#float "\(in Python v3.11\)") 
    
Elevation camera angle on the specified the camera_position. 

Returns: 
     

[bool](https://docs.python.org/3.11/library/stdtypes.html#bltin-boolean-values "\(in Python v3.11\)")
    
Examples

```
>>> from ansys.aedt.core.visualization.plot.pyvista import CommonPlotter
>>> obj = CommonPlotter()
>>> obj.set_orientation(camera_position=1, roll_angle=45.0)
