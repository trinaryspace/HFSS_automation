# add_specs_to_report 

VirtualCompliance.add_specs_to_report(_folder : [str](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)")_) 
    
Add specs to the report from a given folder.
All images in such folder will be added to the report. 

Parameters: 
     

**folder**[`str`](https://docs.python.org/3.11/library/stdtypes.html#str "\(in Python v3.11\)") 
    
Folder relative path to compliance report or absolute path.
Examples

```
>>> from ansys.aedt.core.visualization.post.compliance import VirtualCompliance
>>> obj = VirtualCompliance()
>>> obj.add_specs_to_report(folder="directory")

```
