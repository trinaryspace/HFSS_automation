# display_families_options 

property Fields.display_families_options: [dict](https://docs.python.org/3.11/library/stdtypes.html#dict "\(in Python v3.11\)") 
    
Options for the display families type.
Default values are populated automatically when `display_families_type` is set:
  * `DisplayFamiliesType.Histogram`: `{"val_to_sample_at": "", "num_bins": 10}`
  * `DisplayFamiliesType.Statistics`: `{"functions": []}`
  * `DisplayFamiliesType.Cumulative`: no options needed (empty dict).
