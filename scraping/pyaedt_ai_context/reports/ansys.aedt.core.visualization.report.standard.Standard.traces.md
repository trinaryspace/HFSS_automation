# traces 

property Standard.traces: [list](https://docs.python.org/3.11/library/stdtypes.html#list "\(in Python v3.11\)") 
    
List of available traces in the report.
Note
This property works in version 2022 R1 and later. However, it works only in non-graphical mode in version 2022 R2 and later. 

Returns: 
     

`List` `of` `ansys.aedt.core.modules.report_templates.Trace` 
    
Examples

```
>>> from ansys.aedt.core.visualization.report.common import CommonReport
>>> obj = CommonReport()
>>> obj.traces

```
